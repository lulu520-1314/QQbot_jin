# 06 · 音色模型与训练

## 1. 先选择路线：你的音色从哪来

| 方案 | 像你吗 | 成本 | 适合 |
|---|---|---|---|
| **公开 RVC 模型**（推荐起步） | 像"那个模型"，不像你 | 免费、几分钟 | 只要好听，不要求像本人 |
| **RVC 训练自己的声音** | 很像（唱歌） | 需要素材 5~10 分钟 + GPU 1 小时 | 想用自己的声音唱歌 |
| **GPT-SoVITS 微调** | 最像（说话） | 素材 5~10 分钟 + GPU 1 小时 | 日常语音不再经过 RVC，更快更像 |
| GPT-SoVITS 零样本（默认） | 中等 | 0 | 用 8 秒参考音直接说话 |
| **Seed-VC** | 中等 | 免费、CPU 可跑 | 零样本变声，质量一般 |
| **UVR5 / MDX23** | — | 免费 | **分离**人声/伴奏，训练素材提纯必备 |

> 作者的最终组合：**说话 = GPT-SoVITS 零样本 + RVC 换音色**；**唱歌 = RVC 换音色**。
> GPT-SoVITS 微调是"更近一步"的可选项。

## 2. 换音色（最简单）

> 默认模型「温柔少女16」的下载地址与更多模型仓库见 [音色模型仓库与来源](13-音色模型仓库与来源.md)。

1. 下载 `.pth`（有的还带 `.index`）
2. 放进 `rvc_pack\Retrieval-based-Voice-Conversion-WebUI-main\assets\weights\`
3. 有 index 的话，改成和模型同名的 `.index`
4. 改 `rvc_model.txt` 为模型文件名，重启 RVC 服务（或运行切换脚本）

公开模型去哪儿找（**自行确认授权/版权**）：

- HuggingFace：`lowo/RVC-weights`（约 500 个模型）
- 各类社区整合包、模型站（自行甄别）

作者的默认模型：`温柔少女16.pth`（成熟自然不"夹"），备选 `yujie`（御姐）、`Yamine`（清亮高音域）。

> **音色 = 模型决定的**。觉得"夹"、不像、闷，换模型比调参有效。

## 3. 训练 RVC 模型（用自己的声音唱歌）

### 3.1 准备素材

| 项 | 要求 |
|---|---|
| 内容 | **唱歌**（训练唱歌模型）或说话（训练说话模型），不要混 |
| 时长 | **5~10 分钟**干净人声（作者用了 5.7 分钟） |
| 音域 | 覆盖你常唱的音区；高音别硬喊（会学到"挤"的音色） |
| 质量 | 无伴奏、无混响、无爆音；**UVR5 分离过的歌**可用但要挑干净的段落 |
| 切分 | 3~12 秒一段，峰值归一到 0.9 |

### 3.2 数据集整理

仓库自带脚本（推荐）：

```bash
python scripts/build_dataset.py --input "我的清唱.m4a" --out dataset
```

它会按静音切句、过滤过短片段、峰值归一、统一 48k 单声道。下面是等价的手写版本。

```python
# 伪代码：从长录音切段 + 归一化
import librosa, soundfile as sf, numpy as np
y, sr = librosa.load("raw.wav", sr=48000, mono=True)
for i, chunk in enumerate(chunks(y, seconds=8)):   # 自己按静音切
    peak = np.max(np.abs(chunk))
    sf.write(f"dataset/{i}.wav", chunk * (0.9 / peak), sr)
```

### 3.3 训练（RVC WebUI 2.3）

本仓库的 `rvc_pack/` 就是训练/推理代码。全流程：

1. 启动 WebUI：`python infer-web.py`（或在云端跑命令行）
2. **训练页**：
   - 实验名：`xiaojing`
   - 采样率 **48k**、版本 **v2**、`f0` 提取用 **rmvpe**
   - 批量 4~8、**epoch 20~30**、`save_every_epoch 5`
   - 数据集放到 `dataset/<实验名>/`
3. **特征提取**：点 train 前先跑 `1-get-text`→`2-get-hubert`→`3-get-semantic`（WebUI 自动）
4. **训练**：V100 约 15~30 分钟 / 200 epoch
5. **导出小模型**：`extract_small_model.py` → `assets/weights/xiaojing.pth`
6. **建索引**：`train_index.py` → `added_IVF*.index`

### 3.4 云端训练踩坑清单（作者实际遇到）

- 镜像里没有 `python` 命令 → 用绝对路径 `/home/vipuser/miniconda3/bin/python`
- 没有 `ffmpeg` → `apt install ffmpeg`
- `numpy 2.x` 冲突 → `pip install numpy==1.26.4 librosa==0.10.2`
- 缺 `huggingface_hub`、`scipy` → 补装
- hubert 模型要放 `assets/hubert_base/`（content-vec bin + facebook configs）
- rmvpe 路径是 `assets/rmvpe/rmvpe.pt`（不是 `assets/rmvpe.pt`）
- `extract_small_model` 需要 `assets/weights/` 目录已存在
- **训练完立刻下载模型**（作者遇到实例到期，模型丢过一次）

### 3.5 训练参数对音色的影响

| 参数 | 效果 |
|---|---|
| epoch 太少（<50） | 音色不稳、发虚 |
| epoch 太多（>500）且素材少 | 过拟合，听感"塑料" |
| rmvpe vs pm | rmvpe 准、pm 快 |
| 48k vs 40k | 48k 高频细节更好 |
| 素材里有破音/喊 | 模型学会"挤"，输出沙哑 |

## 4. GPT-SoVITS 微调（日常语音进阶）

零样本（默认）已经能用；想更像自己、且省掉 RVC 那一层，就微调：

1. 素材：**说话** 5~10 分钟（和参考音同样要求）
2. 打标：用 `faster-whisper` 转写（中文小模型即可）
3. 生成 `.list`：`路径|说话人|语言|文本`
4. 训练 s2（SoVITS，约 8 epoch，A100 约 20~30 分钟）
5. 导出 `SoVITS_weights/xxx.pth` + `GPT_weights/xxx.ckpt`
6. 把 `say.py` 的 API 调用换成带 `gpt_path` / `sovits_path` 的推理模式

> 注意：GPT-SoVITS 2025 主分支和 v2 预训练权重的配置**不兼容**，
> 训练要用对应版本的代码（作者踩过这个坑，见 08 章）。想省事可以直接用官方 WebUI 的"一键微调"。

## 5. 分离工具对比（UVR5 / demucs / MDX）

> 完整用法、界面步骤、参数选择见 [声音分离方案](12-声音分离方案（demucs与UVR5）.md)。

| 工具 | 速度 | 质量 | 备注 |
|---|---|---|---|
| **demucs htdemucs** | 1x 实时 | 好 | 本项目默认，`pip install demucs` |
| **demucs htdemucs_ft** | 4x 慢 | 最好 | 人声更干净，训练素材首选 |
| UVR5 (MDX-Net) | 快 | 好 | Windows 图形界面友好 |
| MDX23C | 慢 | 极好 | 高质量分离 |

> 训练素材用**更好的分离**（htdemucs_ft / UVR5），成品翻唱用 htdemucs 平衡速度即可。

## 6. 常见音色问题排查

| 现象 | 原因 | 解法 |
|---|---|---|
| 不像本人 | 素材脏/太少/混了别人声音 | 重做数据，只留干净段落 |
| 沙哑 | 素材里有破音/喊，或源人声沙哑 | 清洗素材；RVC protect 0.3~0.4；EQ 衰减 |
| 发闷 | 音高偏低 | 自动定调目标调高（290→300+） |
| "夹"、像小孩 | 模型本身偏幼；或升了整整一个八度(+12) | 换成熟模型；pitch 控制在 +5~+7 |
| 高音上不去 | 超出训练音域 | 降 key；或补录高音素材重训 |
