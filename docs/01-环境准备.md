# 01 · 环境准备

本文列的是**作者实际使用的环境**。版本不必完全一致，但大版本建议对齐（尤其 Python 与 torch），否则 RVC 相关依赖容易打架。

## 1. 电脑要求

| 项 | 最低 | 推荐（作者配置） |
|---|---|---|
| 系统 | Windows 10 x64 | Windows 11 x64 |
| 内存 | 8 GB | 16 GB 以上 |
| 硬盘 | 20 GB 空闲 | 40 GB 以上（模型 + 数据集 + 曲库） |
| GPU | **不需要** | 有 NVIDIA 卡会快很多（训练/批量转换） |
| CPU | 4 核 | 8 核以上（RVC 推理吃 CPU） |

> 作者的整套流程**纯 CPU 也能跑**：一首 25 秒翻唱约 3~5 分钟，一句语音约 30 秒。
> 训练 RVC 模型建议租 GPU（见 [音色模型与训练](06-音色模型与训练.md)），推理不需要。

## 2. 必装软件

```text
Python 3.10 或 3.12   ← 要装两个：一个给 DSH 插件（3.10），一个给 RVC/音频（3.12 也行）
Node.js 20+           ← DSH 本体
Git                   ← 拉代码
FFmpeg（带 ffprobe）   ← 所有音频处理
QQ NT 9.9.x + NapCat  ← QQ 机器人框架
DeepSeek Harness      ← 大脑
```

### 2.1 Python

- 建议把音频相关的 Python 单独放一个目录，例如 `D:\software\Voice\py310\python.exe`
- 关键依赖（RVC/音频）：

```bash
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple ^
  numpy==1.26.4 scipy librosa==0.10.2 soundfile ^
  torch torchaudio --index-url https://download.pytorch.org/whl/cpu ^
  faiss-cpu praat-parselmouth ^
  transformers==4.49.0 ^
  demucs==4.1.0 ^
  requests paramiko
```

> **踩过的坑（务必注意）**
> - `numpy 2.x` 与 RVC 依赖不兼容 → **锁 1.26.4**
> - `transformers ≥ 4.50` 在 torch < 2.6 时会报 `torch.load` 安全校验错误 → 音频环境锁 **4.49.0**
> - GPT-SoVITS 需要 `transformers ≥ 4.51`，所以**两个环境分开**（语音服务用 RVC 环境；GPT-SoVITS 单独 venv）
> - Windows 上 `faiss` 用 `faiss-cpu` 就够了

### 2.2 FFmpeg

解压到任意目录，确认能跑：

```bash
ffmpeg -version
ffprobe -version
```

脚本里默认路径是 `D:\software\Voice\ffmpeg\package\ffmpeg.exe`，**换成你的路径**（见 [自定义](09-自定义与扩展.md)）。

### 2.3 Node.js / DSH

- Node 20+，装完 DSH 桌面版即可
- DSH 的插件目录在 `%USERPROFILE%\.dsh\profiles\desktop\`

### 2.4 QQ + NapCat

1. 装 **QQ NT 9.9.x**，登录**小号**（机器人号）
2. 下载 [NapCat](https://github.com/NapNeko/NapCatQQ)（作者用 v4.18.x），解压后运行 `launcher.bat`，扫码/密码登录同一个 QQ
3. NapCat 的 OneBot 配置：**反向 WebSocket**，地址 `ws://127.0.0.1:8643`，token 自己设一个（插件配置里填同一个）
4. NapCat 默认 HTTP 端口 3000、WS 3001 —— 如果被 Windows 保留端口占用（2985~3084 常被系统保留），会报 `EACCES`。**改成 13200/13201**：

```text
# NapCat 配置(config/onebot11_<QQ>.json)
"httpServers": [{ "port": 13200 }],
"websocketClients": [{ "url": "ws://127.0.0.1:8643", "token": "<你的token>" }]
```

> 检查端口是否被系统保留：`netsh interface ipv4 show excludedportrange protocol=tcp`
> 报 EACCES 就换到 10000 以上。

## 3. 服务端口一览

| 服务 | 端口 | 说明 |
|---|---|---|
| DSH 插件（OneBot WS 服务端） | 8643 | NapCat 连过来 |
| NapCat HTTP API | 13200 | 脚本发消息/发文件用 |
| NapCat WS | 13201 | 备用 |
| GPT-SoVITS TTS | 9880 | 文字转语音 |
| RVC 转换服务 | 9850 | 换音色（本项目自带 `rvc_server.py`） |
