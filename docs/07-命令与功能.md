# 07 · 命令与功能

## 1. 命令表

### 会话

| 命令 | 权限 | 说明 |
|---|---|---|
| `/new` | 管理员 | 开新会话（清上下文、重读人格） |
| `/workspace [路径\|序号\|list]` | 管理员 | 查看/切换工作区 |
| `/preset [id\|序号]` | 管理员 | 查看/切换 agent 预设 |
| `/session [序号]` | 管理员 | 查看/切回历史会话 |
| `/permission [w\|f]` | 管理员 | w=工作区可写需审批；f=全盘免审批 |

### 输出

| 命令 | 权限 | 说明 |
|---|---|---|
| `/mode [interim\|instant]` | 管理员 | 合并卡片 / 逐条即时 |
| `/plan [off\|内容]` | 管理员 | 计划模式 |
| `/serious`（别名 `/专业` `/认真`） | 所有人 | 专业问答模式，认真解答不卖萌 |

### 查询

| 命令 | 说明 |
|---|---|
| `/status` | 会话全景 |
| `/doctor [export]` | 体检 / 导出诊断包 |
| `/id` | 会话标识 |
| `/model [--default] [provider] [model]` | 查看/切换模型 |

### 操作

| 命令 | 说明 |
|---|---|
| `/stop` | 停止当前生成 |
| `/steer <补充>` | 给正在跑的任务补一句话 |
| `/retry` | 重跑上一条 |
| `/ocr` | 识别最近一张图片文字 |
| `/remember <内容>` / `/记住` | 记一件事（`主题=内容` 覆盖旧记忆） |
| `/recall <关键词>` / `/记忆` | 查记忆 |

### 其他

| 命令 | 说明 |
|---|---|
| `/点歌 [原唱] 歌名 [段落] [时长] [变调] [语音条]` | 小鲸唱 / 原曲切片 |
| `/今日气运`（`/抽签`） | 抽今天的气运 |
| `/明日气运` | 抽明天 |
| `/weekly`（`/周报`） | 群活跃周报 |
| `/help [命令]` | 帮助（两条气泡：标题 + 分组卡片） |

> **`/help` 的设计**：第一条只发「可用命令（仅管理员）：」，第二条是完整分组卡片（`noSplit` 整块发送，不按行拆气泡）。

## 2. 主动功能

| 功能 | 触发 | 实现 |
|---|---|---|
| 表态/表情包 | 任何场合自主判断 | `workspace/stickers/`，文件名即标签 |
| 语音 | 有人说「发语音/念/说…」 | `say.py`（TTS+RVC） |
| 唱歌 | 「唱…」「点歌」 | `cover.py` 或 `/点歌` |
| 戳一戳 | 别人戳它 | 插件 `notice` 事件 + 随机回复 |
| 新闻派送 | 每天 19:00 | `news_push.py` + Windows 计划任务 |
| QQ 空间说说 | 管理员要求 | NapCat `send_qzone_msg` |
| 群活跃周报 | `/weekly` | 统计消息记录 |

## 3. 点歌细节

```text
/点歌 晴天                     → 小鲸唱：自动副歌 25 秒 + 语音条
/点歌 晴天 副歌 20秒 升1key     → 指定段落/时长/变调
/点歌 原唱 晴天 副歌 20秒       → 原曲切片（不变声，秒出）
```

- 找不到歌 → 提示 + 相近歌名建议 + 告知如何添加
- 曲库：`曲库目录.txt`，一行一个文件夹
- 语音条上限 59 秒，文件形式最多 3 分钟
- 想按歌词行切片需要同名 `.lrc`

## 4. 新闻派送（可选）

`scripts/news_push.py`：

- 每晚 19:00 用 Windows 任务计划触发
- 抓 RSS（作者用 IT之家），取 5~8 条，发到指定群/私聊
- 配置项在文件顶部：`GROUPS`、`PRIVATE`、`COUNT`、`RSS_LIST`
- 需要 NapCat 的 HTTP API 在 13200

## 5. 表情包

```
workspace/stickers/
├─ 01_开心.png
├─ 34_区_无语.png
└─ README.md      # 目录表：文件名 → 什么时候用
```

- 文件名格式：`编号_标签.png`（标签是中文，方便模型挑）
- `README.md` 里维护一张「标签 → 使用场合」表，模型会照着挑
- 加新图：丢进目录 + 在 README 加一行即可
