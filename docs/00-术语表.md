# 术语表 · 这个项目里每个名词是什么

先花 3 分钟看完这一章，后面所有文档都不会再"天书"。

## 一、整体链路

```
你（QQ） ⇄ QQ 客户端(NapCat) ⇄ DSH(大脑) ⇄ 声音服务(TTS + RVC) ⇄ 返回语音/歌曲
```

---

## 二、核心组件

### DeepSeek Harness（DSH）
本项目使用的 **AI Agent 宿主程序**。它负责：

- 运行大模型对话（DeepSeek 等）
- 加载插件（`dsh-onebot-qq` 就是其中一个）
- 读取 `AGENTS.md` 人格设定
- 调用工具/脚本

**可以理解为"机器人的身体和大脑外壳"**，关掉 DSH 机器人就下线。

### NapCat
一个**QQ 协议端**（第三方 QQ 客户端框架，基于 QQ NT）。

- 作用：让程序能像真人一样登录 QQ、收发消息
- 用法：登录你的 QQ **小号**，对外提供 **OneBot v11 HTTP/WebSocket 接口**
- 为什么不用官方 API：QQ 官方机器人 API 限制多（不能进普通群、不能主动发语音/文件）

> 同类还有 Lagrange、LLOneBot 等，NapCat 目前最稳定。

### OneBot v11 / 反向 WebSocket（反向 WS）
- **OneBot v11**：一套"QQ 机器人接口标准"，规定消息长什么样、怎么发
- **WebSocket**：长连接，双方可以随时互发数据
- **反向**：由 **NapCat 主动连到 DSH**（而不是 DSH 去连 NapCat）
  - 好处：DSH 只需要开一个端口等连接，不用管 QQ 在哪台机器
  - 本项目：NapCat → `ws://127.0.0.1:8643` → DSH 插件的 WS 服务端

```
NapCat ──(主动连接 ws://127.0.0.1:8643)──► DSH 插件
```

### 插件 `dsh-onebot-qq`
把 OneBot 消息翻译成 DSH 能理解的事件，再把 DSH 的回复发回 QQ。
它同时提供 `/help`、`/点歌`、`/new` 等命令。

## 三、声音相关

### TTS（Text To Speech，文字转语音）
把**文字**变成**人声**。

- 本项目用 **GPT-SoVITS** 做 TTS
- 输出是"读出来的话"，不是唱歌

### GPT-SoVITS
开源的中文/多语种语音合成 + 声音克隆模型。

- **零样本模式**：给一段 8~15 秒参考音 + 参考音文字，就能用那个音色读任何文字（不需要训练）
- **微调模式**：用 5~10 分钟素材训练，得到更像本人的模型
- 本项目默认用零样本（够用、快）；微调是进阶选项

### RVC（Retrieval-based Voice Conversion，检索式声音转换）
把**一段人声**换成**另一个音色**，保持内容和语气不变。

- 需要事先训练/下载一个 `.pth` 音色模型
- **唱歌必须用它**（TTS 只会说话，不会唱）
- 本项目用 RVC 做两件事：
  1. 唱歌：原曲人声 → 目标音色
  2. 日常语音：TTS 结果 → 目标音色（更统一）

### 音色模型（`.pth` / `.index`）
- `.pth`：音色权重文件（约 50MB），决定"像谁"
- `.index`：检索索引（可选，几十~几百 MB），提升相似度
- 换模型 = 换音色，不用改代码

### demucs
Meta 开源的**音源分离**工具：把一首歌拆成"人声"和"伴奏"。

- 翻唱第一步就是分离
- `htdemucs`：快；`htdemucs_ft`：慢但更干净

### UVR5（Ultimate Vocal Remover 5）
**图形界面**的人声/伴奏分离软件，Windows 上很流行。

- 内置 MDX-Net、VR、Demucs 等多种模型
- 优点：可视化、好上手、能批量
- 用途：给训练素材做高质量分离，或替代 demucs 做翻唱分离
- 本项目支持"用 UVR5 分离好的两条轨"直接跑：`cover.py --vocals 人声.wav --inst 伴奏.wav`

### Seed-VC
另一种**零样本变声**方案（不需要训练音色模型，给参考音就能换声）。

- 优点：不用训练
- 缺点：质量和稳定性一般，CPU 上慢
- 本项目没用作默认方案，但文档里保留了对比（见 06 章）

### SVC / VC
- **SVC** = Singing Voice Conversion（歌声转换），RVC 属于这一类
- **VC** = Voice Conversion（声音转换，说话/唱歌都行）

## 四、音频处理常见名词

| 名词 | 含义 |
|---|---|
| **采样率** | 每秒采样点数，48kHz 比 40kHz 保留更多高频细节 |
| **f0 / 基频** | 声音的音高（男声约 100~250Hz，女声约 180~400Hz） |
| **半音 / key** | 音高单位；+12 半音 = 升高一个八度 |
| **音域** | 一个人/模型能舒服唱到的音高范围 |
| **LUFS** | 响度单位；-14 LUFS 约等于主流音乐平台响度 |
| **限幅（limiter）** | 防止音量超过 0dB 造成"爆音" |
| **压缩（compressor）** | 压小动态，让小声不虚、大声不炸 |
| **EQ** | 均衡器，按频率增减（如削 6.5kHz 去沙哑） |
| **降噪/去齿音** | 去掉嘶嘶声、齿音 |
| **CQT / chroma / MFCC** | 音频特征，用于分析音高、音色、相似度 |
