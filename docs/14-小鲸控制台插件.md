# 14 · 小鲸控制台插件（lulu-dsh-xiaojing-panel）

把「人设、语料、表情包、音乐库、音色、定时任务、外部服务」全部收进 DSH 设置页的一个自研插件。
QQ 收发仍由 `dsh-onebot-qq` 负责，本插件只做**管理面板 + 两个后台能力**（定时任务、表情包自动收录）。

## 装它

DSH → 插件 → 添加插件 → 输入包名：

```
lulu-dsh-xiaojing-panel
```

> 也已在 npm 发布：https://www.npmjs.com/package/lulu-dsh-xiaojing-panel

装好后：设置 → **小鲸控制台**。

## 七个标签页

| 标签 | 能干什么 |
|---|---|
| 人格人设 | 直接编辑 `workspace/AGENTS.md`（保存后 QQ 里 `/new` 生效）、用系统编辑器打开 |
| 表情包 | **收藏**（小鲸能发的）与**收录**（自动收藏待整理）两个可折叠区；缩略图预览、点图看大图、搜索、全选、删除、重命名、批量加前缀、移入收藏 |
| 音乐库 | 编辑 `曲库目录.txt`（`/点歌` 与聊天点歌共用） |
| 音色模型 | 下拉选 `.pth` → 写 `rvc_model.txt`；打开模型目录 |
| 定时任务 | 可视化增删任务（文本 / 脚本），支持**测试发送**、复制；高级 JSON 编辑 |
| 服务管理 | NapCat(13200) / RVC(9850) / TTS(9880) 的**状态 + 启动/停止**（启动前自动清理重复进程） |
| 配置文件 | 一键打开人设、曲库、模型、任务、记忆库、表情包、语音产物、声音工坊 |
| 语料库 | 文件列表 + 新建 / 编辑 / 保存 / 删除（默认目录 `workspace/语料库`） |
| 语音/唱歌参数 | 6 档语音情绪（语速/清晰度/高低）与唱歌参数（音高/保护度/音量/响度），带人话说明与「恢复默认」 |
| 长文转图 | 开关、触发字数、页脚文字、字体（写回 `dsh-onebot` 的 `textImageThreshold` 等配置） |

## 架构（为什么不走 Typert Remote）

```
设置页 React 组件  ──fetch──►  本机 HTTP API（127.0.0.1:9877，占用自动顺延）
                                     │
                                     ├─ 读写 workspace 文件（人设/语料/表情）
                                     ├─ 读写 params.json、rvc_model.txt
                                     ├─ 启停外部进程（NapCat/RVC/TTS）
                                     ├─ 定时任务调度（每 30 秒）
                                     └─ 表情包自动收录（每 5 分钟扫 mediaDir）
```

选 HTTP 的理由：只服务本机、协议简单、出问题容易用 curl 定位，也不用维护 Typert descriptor 契约。

## 稳定性设计（踩过的坑）

| 设计 | 解决什么问题 |
|---|---|
| 包内自带 `cordis.patch.yml` + `dsh.profile.bundles` 登记，**profile patch 里不再重复 insert** | 同一插件双实例注册 → 宿主崩溃循环 |
| `apply()` 整体 try/catch，异常只打日志 | 插件异常不拖垮 DSH |
| HTTP 端口被占用自动 +1 顺延 | 不会因为端口冲突起不来 |
| 服务启动前 `killAllByCmd('rvc_server')` | 残留进程占着 9850，导致"换模型不生效" |
| RVC 服务自带 `_already_running()` 检查 | 新进程发现端口已被占就退出，不再偷偷跑在 9851 |
| 定时器回调全部包 try/catch | 单个任务失败不影响其他任务 |

## 默认配置

配置文件是 profile 的 `cordis.patch.yml` 里 `lulu-dsh-xiaojing-panel` 条目（可覆盖）：

```yaml
port: 9877
workspaceDir: D:\software\QQBot\workspace
voiceDir: D:\software\Voice
musicDirsFile: D:\software\QQBot\曲库目录.txt
schedulesFile: D:\software\QQBot\schedules.json
rvcModelFile: D:\software\Voice\rvc_model.txt
mediaDir: D:\software\QQBot\media
corpusDir: D:\software\QQBot\workspace\语料库
paramsFile: D:\software\Voice\params.json
autoCollectMinutes: 5
```

## HTTP API（方便排查/二次开发）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/ping` | 存活检查 |
| GET | `/state` | 全量状态（路径、模型列表、服务状态、任务） |
| GET/POST | `/persona` | 读/写 AGENTS.md |
| POST | `/music` | 写曲库目录 |
| POST | `/rvc-model` | 写音色模型名 |
| GET | `/stickers` | 收藏 + 收录列表 |
| GET | `/img?kind=saved|collected&name=` | 取表情图 |
| POST | `/stickers/{delete,rename,promote,prefix,collect}` | 表情包操作 |
| GET/POST | `/corpus`、`/corpus/file`、`/corpus/delete` | 语料库 |
| GET/POST | `/params` | 语音/唱歌参数 |
| GET/POST | `/card` | 长文转图配置（读写 dsh-onebot 配置块） |
| GET/POST | `/schedules`、`/schedules/test` | 定时任务 |
| POST | `/service` `{name,action}` | 启停 NapCat/RVC/TTS |
| POST | `/open` `{path}` | 用系统程序打开文件/目录 |
| GET | `/file?path=` | 读任意文本文件（限 200KB） |

## 开发与发布

源码：本仓库 `plugin/lulu-dsh-xiaojing-panel/`。

```bash
# 本地开发：改完直接覆盖 node_modules 里那份，或
cd plugin/lulu-dsh-xiaojing-panel
npm publish --access public   # 先 npm version patch
```

## 已知限制

- 面板只监听 `127.0.0.1`（不对外网开放）
- 定时任务是**进程内**调度：DSH 没开就不会跑（需要长期可靠请用 Windows 任务计划）
- 表情包自动收录依赖 `dsh-onebot` 把入站图片落到 `mediaDir`（文件名 `media_*`）
