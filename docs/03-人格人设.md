# 03 · 人格人设（可完全自定义）

机器人的"魂"就是一个文件：`workspace/AGENTS.md`。
DSH 每次开新会话都会读它，所以**改人格 = 改这个文件**，不用动代码。

默认人设是作者调过的**「小鲸 / 大肥鱼」**，完整版见 [`../configs/AGENTS.example.md`](../configs/AGENTS.example.md)。

## 1. 默认人设概览

| 维度 | 设定 |
|---|---|
| 名字 | 小鲸（自称"本鲸/我"，"本鲸"最多 1/3 次） |
| 性格 | 日常=撒娇为主 + 傲娇点缀（约 7:3）；可切「傲娇」「温暖大姐姐」 |
| 口头习惯 | 不用编号列表、不用括号描写动作、多条短气泡、口语化 |
| 作息 | 工作日 9:00–12:00 / 14:00–18:00 群聊降低活跃（回「目前deepseek模型定价处于高峰时段啦，根据宿主要求本鲸活跃度会有所降低哦」） |
| 特殊 | 会发表情包、会发语音、会唱歌、会戳回去、会 @ 人、会发 QQ 空间 |
| 记忆 | `/记住 内容`、`/记忆 关键词`，存 `记忆库.md` |

## 2. 文件结构（建议保留这些章节）

```
一、身份与称呼
二、性格与说话方式（三档模式）
三、群聊行为（引用、@、刷屏控制、高峰时段）
四、表情包使用
五、语音与唱歌（何时发、怎么发、情绪选择）
六、命令与工具（分工：能用工具就别用文字糊弄）
七、宿主/管理员专属规则
八、文件纪律（不许乱建文件）
```

**顺序建议**：越靠前权重越高，最重要的行为放前面。

## 3. 常用自定义

### 3.1 换名字 / 换性格

直接改开头：

```markdown
你是「小鲸」，QQ 上一个有点黏人的女生……（这里写你的设定）
```

三档性格在文中用「日常 / 傲娇 / 温暖大姐姐」分段，并说明切换方式（作者用 `/mode` 命令 + 关键词触发）。

### 3.2 改说话风格

- 禁止项写成**铁律**，比"尽量不要"有效：
  > 不许用编号列表；不许在括号里写动作；不许一句话超过 40 字
- 想让它更短：加「一次回复 1~3 个气泡，每个气泡 ≤30 字」

### 3.3 自定义触发词

例：

```markdown
- 用户说「抱抱」→ 撒娇语气回一句 + 发表情包 12_害羞.png
- 用户说「唱歌」→ 走 /点歌 流程（见 05 章）
```

### 3.4 多机器人 / 换场景

把人设文件复制一份改内容，配合插件配置 `workspacePath` 指向不同目录，就能跑不同人格的机器人。

## 4. 记忆系统

- `/记住 内容` → 追加到 `记忆库.md`
- `/记住 主题=新内容` → 覆盖同主题旧记忆
- `/记忆 关键词` → 检索

> 记忆不会自动写，只有命令触发；`/new` 只清会话上下文，不清记忆库。

## 5. 生效方式

改完 `AGENTS.md`：

- 新建会话：QQ 里发 `/new`
- 或重启 DSH

**注意**：`/new` 会清空当前聊天的上下文（人格文件本身不丢）。
想保留重要信息，先让它 `/记住`。
