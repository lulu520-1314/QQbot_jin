# 10 · 常见问题 FAQ

## Q1. 必须要有 GPU 吗？

不需要。
- **推理**（语音、唱歌）纯 CPU 可跑：一句语音约 30 秒，一首 25 秒翻唱约 3~5 分钟
- **训练**（RVC/GPT-SoVITS 微调）建议租 GPU，1 小时几块钱

## Q2. 音色模型从哪来？能商用吗？

- 公开模型仓库：HuggingFace `lowo/RVC-weights`（约 500 个）等
- **版权**：真人/明星/声优模型仅限个人学习娱乐，**不要公开传播或商用**
- 想商用，就用自己训练、或明确可商用授权的模型

## Q3. 为什么我的翻唱"夹"/不像？

90% 是**模型本身**的音色（偏幼、偏甜）。换一个成熟些的模型立刻改善。
剩下的 10% 是音高：低了会闷，高了会尖。

## Q4. 为什么唱到高音就破音？

超出模型训练音域。解法按顺序：
1. 降 key（`--pitch` 往下调）
2. 换主歌段落（避开最猛的高潮）
3. 补录高音素材重训模型

## Q5. 人声和伴奏对不上/跑调？

**只降了人声没降伴奏**。本项目已内置"同步变调"，如果你自己改代码务必保留。

## Q6. 结尾总是唱一半？

固定时长硬切了。本项目会找换气点自动补到整句；如果你自己写，记得加这一步。

## Q7. 语音开头第一个字听不清？

RVC 首帧缺上下文。**转换前垫 300ms 静音，转换后裁掉**。

## Q8. 说话像唱歌/像机器人？

- 参考音用了唱歌素材 → 换成**说话**素材
- 参考音太短/有伴奏/有回声 → 换干净的 8~15 秒
- 语速太慢 → `--speed 1.2~1.3`

## Q9. 中英混合读不对？

用 `--lang auto`（本项目默认），会按语言分段合成再拼接。
纯英文想更地道 → 提供英文参考音。

## Q10. 服务老是挂？

- RVC：`say.py`/`cover.py` 会自动拉起；也可手动双击启动脚本
- TTS：写个开机自启或在 `say.py` 里加同样的自动拉起
- **不要**用 20 秒轮询看门狗，没必要且占资源

## Q11. 改了人格没反应？

`AGENTS.md` 只在会话启动时读取 → `/new` 或重启 DSH。
`/new` 会清当前聊天记忆；重要信息先 `/记住`。

## Q12. 改了插件代码没反应？

插件代码在 DSH 进程**启动时加载** → 必须重启 DSH，`/new` 不行。

## Q13. 端口被占用 / EACCES？

Windows 会保留一段端口（常见 2985~3084）。查：

```powershell
netsh interface ipv4 show excludedportrange protocol=tcp
```

换成 10000 以上的端口（作者用 13200/13201）。

## Q14. 点歌说找不到，但我明明有这首歌？

- 歌名要接近（支持一定模糊匹配）
- 文件要在 `曲库目录.txt` 列出的文件夹里
- 支持 mp3/flac/m4a/wav/ogg/aac

## Q15. 一首歌要多久？

| 步骤 | CPU | GPU |
|---|---|---|
| 分离 | 30~60s | 5~10s |
| RVC 转换 | 20~40s | 2~4s |
| 混音 | 2s | 2s |
| **合计** | **3~5 分钟** | **<1 分钟** |

## Q16. 能同时跑多个 QQ 号吗？

可以：每个号一个 NapCat 实例 + 一份插件配置 + 一个 DSH 工作区（不同人格/记忆）。

## Q17. 聊天记录/隐私会不会泄露？

- 所有模型和服务都在**本机**（或你自己的云服务器）
- 只有 DSH 对话会经过你配置的模型服务商
- 本仓库不含任何个人信息，配置文件请勿提交

## Q18. 想让它更聪明/更便宜？

- `/model` 切换 DSH 使用的模型（便宜模型日常聊天，复杂问题用强模型）
- 加 `/serious` 专业模式处理技术问题
