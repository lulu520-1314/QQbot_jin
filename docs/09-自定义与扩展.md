# 09 · 自定义与扩展

这一章讲清楚：**哪些地方可以改、改哪个文件、改完怎么生效**。

## 1. 改性格 / 人设

| 想改 | 改哪里 | 生效 |
|---|---|---|
| 名字、语气、性格 | `workspace/AGENTS.md`（参考 `configs/AGENTS.example.md`） | `/new` 或重启 DSH |
| 触发词、固定回复 | 同上，写在规则里 | 同上 |
| 记忆 | QQ 里 `/记住 内容` | 立即 |
| 表情包 | `workspace/stickers/`（文件名即标签）+ `README.md` 目录表 | 立即 |

## 2. 换音色

```powershell
# 1) 把 .pth 放进
#    rvc_pack\Retrieval-based-Voice-Conversion-WebUI-main\assets\weights\
# 2) 有 index 就改名成 <模型名>.index 放同目录
# 3) 改 rvc_model.txt 为模型文件名
# 4) 重启 RVC 服务（约 60 秒）
```

或直接跑你写的切换脚本（作者用 `切换RVC音色.cmd`）。

> 同一模型**同时用于语音和唱歌**——换一次两边都变。

## 3. 改曲库

```
曲库目录.txt        # 每行一个文件夹
C:\Users\<你的用户名>\Music
D:\我的音乐
```

- `/点歌` 和聊天点歌共用这个文件
- 支持 mp3/flac/m4a/wav/ogg/aac
- 想精确到歌词行需同名 `.lrc`

## 4. 改语音参数

| 想改 | 位置 |
|---|---|
| 情绪档位（语速/提亮/音高） | `scripts/say.py` 里 `emo = {...}` |
| 默认语速 | `say.py` 的 `mode_speed` |
| 首字清晰处理（垫静音时长） | `say.py` 里 `pad_ms = 300` |
| 参考音 | `refs/ref.wav` + `refs/ref.txt` |

## 5. 改唱歌参数

| 想改 | 位置 | 说明 |
|---|---|---|
| 副歌检测窗口 | `cover.py` `find_hook()` | 默认 25 秒 |
| 前奏上限 | `--intro-max`（默认 8） | |
| 目标音高 | `cover.py` 里 `290.0` | 觉得闷就调高（300~320） |
| 音高上下限 | `max(-2, min(6, ...))` | 破音多就收窄 |
| 混音比例 | 那串 `-filter_complex` | 人声 1.2 / 伴奏 0.75 |
| 响度 | `loudnorm=I=-14:TP=-2.5` | 想更响改 -13，注意爆音 |
| RVC protect | payload 里 `"protect": 0.35` | 小=更干净，大=更保留原唱细节 |
| RVC index_rate | `--index-rate`（0.5） | 大=更像原唱，小=更像模型 |

## 6. 加新功能（三种方式）

### 6.1 纯人格层（最简单）

在 `AGENTS.md` 里写：

```markdown
- 用户说「天气」→ 调用 weather.py 查天气，把结果用口语说一遍
```

配合一个脚本 `workspace/tools/weather.py`。

### 6.2 加插件命令

改 `node_modules/dsh-onebot-qq/lib/commands.js`：

```js
{ name: '天气', aliases: ['weather'], group: '其他', help: '查天气：/天气 城市',
  handler: async (ctx, chatId, arg) => {
    const out = runQqScript('D:\\software\\QQBot\\weather.py', [arg]);
    await ctx.sendToChat(chatId, out);
  } }
```

> 改完**重启 DSH**；插件升级会覆盖，记得备份 patch 或写个补丁脚本。

### 6.3 定时任务

Windows 任务计划程序：

```
程序:  D:\software\Voice\py310\python.exe
参数:  D:\software\QQBot\news_push.py
触发:  每天 19:00
```

## 7. 改插件行为（本地补丁清单）

升级插件后需要重打的补丁：

| 文件 | 改动 |
|---|---|
| `lib/commands.js` | `/help` 两条气泡 + `noSplit`；点歌双模式；去 `/ver`；长超时执行器 |
| `lib/outbound.js` | 多气泡拆行、`noSplit`、过滤模型自注 |
| `lib/connection.js` | `notice`（戳一戳）分发 |
| `lib/index.js` | 戳一戳回复、命令门顺序 |
| `lib/prompt.js` | 平台提示（纯文本、专业模式前缀） |

建议：把补丁写成 git patch 存在自己的私有仓库，升级后 `git apply`。

## 8. 多机器人

- 换一个 `workspacePath` → 另一套人格/记忆/表情包
- 换一个 QQ 小号 + 一份插件配置 → 同时跑多个

## 9. 性能调优

| 目标 | 做法 |
|---|---|
| 语音更快 | 微调 GPT-SoVITS（省掉 RVC 那步） |
| 唱歌更快 | 有 GPU：demucs 用 CUDA；RVC 用 GPU 版 |
| 省内存 | RVC 服务只加载一个模型 |
| 少占 CPU | 别开轮询看门狗，用"用到时自动拉起" |
