# 05 · 唱歌（翻唱流水线）

## 1. 一句话原理

```
原曲 ──demucs 分离──► 人声 / 伴奏 ──RVC 换音色──► 你的声音 ──混音+限幅──► 语音条
         │                └── 自动选段：找副歌、卡前奏、对齐整句
         └── 自动定调：测原唱音高，反推升/降几个半音（伴奏同步变调）
```

## 2. 用法

```powershell
# 默认：自动副歌 + 自动定调 + 25 秒
python cover.py --song "C:\Music\晴天.mp3" --outdir out

# 自定义
python cover.py --song "...mp3" --start 148 --dur 30 --pitch 5 --outdir out
python cover.py --song "...mp3" --no-mix        # 只要清唱
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--song` | 必填 | 原曲路径 |
| `--start` | 自动 | 不填=自动找副歌；填了=从该秒开始 |
| `--dur` | 25 | 目标时长（会自动补到整句） |
| `--pitch` | 自动 | 不填=自动定调；填了=固定升/降半音 |
| `--intro-max` | 8 | 前奏最长多少秒 |
| `--index-rate` | 0.5 | 检索权重（越低越"借模型"，越高越"像原唱"） |
| `--f0-method` | rmvpe | 音高提取（pm 更快，rmvpe 更准） |
| `--outdir` | 必填 | 输出目录 |

## 3. 五个自动化环节（这是效果的关键）

| 环节 | 做法 | 解决的问题 |
|---|---|---|
| **副歌定位** | 全曲 RMS 滑窗，取持续最响的窗口（排除开头 15%、结尾 8%） | 只说"唱某首歌"时默认唱**热门段落**而不是从头唱 |
| **前奏压缩** | 检测人声进入时间，超过 `intro-max` 就整轨前移 | 前奏太长（原曲可能 20 秒） |
| **自动定调** | 测原唱人声中位 F0 → 目标 290Hz → 半音数，clamp(-2,+6) | 每首歌音域不同，固定值会闷或破音 |
| **同步变调** | 伴奏用 `asetrate+atempo` 降同样半音 | 只降人声会导致**人声和伴奏打架** |
| **整句对齐** | 在目标时长附近找人声 ≥150ms 停顿，自动延长/收短 | 结尾不会切半句 |

## 4. 混音链（防止各种听感问题）

```
人声: 6.5k/9k EQ 衰减(压沙哑) → 压缩(防断气) → 1.2x 音量 → 限幅
伴奏: 0.75x 音量 → 限幅
合并: amix → 3kHz 提亮(吐字) → loudnorm(-14 LUFS) → 限幅(峰值≤-2.5dB)
```

| 问题 | 对应处理 |
|---|---|
| 破音/沙哑 | RVC `protect 0.35`（少保留原唱气声）+ 6.5k/9k 衰减 |
| 断气（长句虚） | 人声压缩 -18dB / 2.0 |
| 爆音 | 双限幅，峰值 -2.7dB 实测无削波 |
| 声音小 | 人声 ×1.2、伴奏 ×0.75、目标 -14 LUFS |
| 吐字糊 | 3kHz +0.8dB 提亮 |
| 跑调 | 人声/伴奏同步变调 |

## 5. RVC 常驻服务

`scripts/rvc_server.py` 把模型常驻内存，避免每次重新加载（单次 CLI 要 60 秒启动）。

```powershell
python rvc_server.py          # 启动，等待 "RVC ready on http://127.0.0.1:9850"
```

接口：

```http
POST http://127.0.0.1:9850/rvc
{"input":"in.wav","output":"out.wav","pitch":5,"protect":0.35,"index_rate":0.5,"f0_method":"rmvpe"}
```

- 模型由 `D:\software\Voice\rvc_model.txt` 决定（写模型文件名即可）
- 换模型：改文件 → 重启服务（约 60 秒）
- 作者写了 `切换RVC音色.cmd` 做这件事（可选，你自己写个 bat 也行）

## 6. 点歌命令（与聊天点歌同一套）

```text
/点歌 晴天                      ← 小鲸唱（默认，3~5 分钟）
/点歌 晴天 副歌 20秒 升1key      ← 指定段落/时长/变调
/点歌 晴天 副歌 语音条          ← 语音条
/点歌 原唱 晴天 副歌 20秒        ← 原曲切片（秒出，不变声）
```

- 默认**语音条**；要文件说「发文件/mp3」
- 找不到歌会提示，并给出相近歌名建议
- 曲库路径在 `曲库目录.txt`（一行一个文件夹）

## 7. 性能

| 步骤 | 耗时（CPU） |
|---|---|
| 分离（demucs） | 30~75 秒 |
| RVC 转换（25 秒片段） | 40~70 秒 |
| 混音 | 2 秒 |
| **合计（第一次）** | **约 2~4 分钟/首** |
| **合计（同歌同段第二次，命中分离缓存）** | **约 1 分钟** |

**分离缓存**：`cover.py` 会把分离结果缓存到 `workspace/voice/stems_cache/`，
同一首歌、同一片段、同一模型，第二次直接复用（实测 143s → 69s）。
换歌/换起点/换模型会重新分离。清理缓存：直接删这个目录。

GPU 会快 10 倍以上，但不是必需。


## 8. 自动化细节（踩坑后加上的）

| 能力 | 做法 | 解决的问题 |
|---|---|---|
| 自动副歌 | 全曲 RMS 滑窗找最响的 25 秒 | 只说"唱某首歌"时别从头唱 |
| 自动定调 | pyin 测原唱中位 F0 → 目标 290Hz → 半音数，clamp(-2~+6) | 每首歌音域不同；yin 会跳八度，必须用 pyin |
| 同步变调 | 伴奏 asetrate+atempo 降同样半音 | 只降人声会"打架" |
| 前奏压缩 | 测人声进入点，超 8 秒整体前移 | 原曲前奏可能 20 秒 |
| 整句对齐 | 目标时长附近找 ≥150ms 换气点，延长/收短 | 结尾不会切半句 |
| 安全增益 | 放大后峰值 >0.95 就整体缩回 | 男声模型 + 增益会削波爆音 |

## 9. 常见故障

| 现象 | 原因 | 处理 |
|---|---|---|
| 换了音色但声音没变 | **多个 rvc_server 进程**，最老的占着 9850 | 全部杀掉只留一个；新版服务已加"端口被占就退出"保护 |
| 切换模型后服务加载旧模型 | 启动早于改 `rvc_model.txt` | 先改文件再重启服务 |
| 爆音/听不清 | 增益过大 + 硬 clip | 用等比缩放；`modelGain` 控制在 1.0~1.15 |
