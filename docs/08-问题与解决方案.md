# 08 · 问题与解决方案（开发全过程踩坑记录）

这一章是作者的"血泪史"：**每一个实际出现过的问题**、原因、修法。
照着搭环境时遇到同样的报错，先来这里搜关键词。

---

## 一、环境与安装

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | NapCat 启动报 `EACCES`，HTTP/WS 端口绑定失败 | Windows 保留了 2985~3084 端口段 | 把 NapCat 端口改到 **13200/13201**；用 `netsh interface ipv4 show excludedportrange protocol=tcp` 查保留段 |
| 2 | 机器人登成了大号（本人 QQ） | NapCat 登录了错误账号 | 退出后重新登录**小号**；启动器写死小号路径 |
| 3 | 官方"大肥鱼"机器人和自建冲突 | 两个 bot 抢同一个 QQ | 插件配置里把官方项 `disabled: true`，改完**重启 DSH** |
| 4 | 域名/URL 打不开 GitHub 下载慢 | 国内网络 | 用 `gh-proxy.com` 前缀、`hf-mirror.com` 镜像 |
| 5 | 云 GPU 实例到期，训练好的模型丢了 | 没及时下载 | **训练完立刻 sftp 下载** `.pth` + `.index` |

## 四、RVC 本地推理

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 21 | `No module named 'tools.cuda_graph'` | 仓库目录缺 `__init__.py` | 在 `tools/ infer/ i18n/ train/ configs/` 各放一个空 `__init__.py` |
| 22 | `Failed to load audio` | 找不到 ffmpeg | 把 ffmpeg 目录加进 `PATH` |
| 23 | `FileNotFoundError: None/xxx.pth` | 未设置 `weight_root` 环境变量 | `os.environ["weight_root"] = <weights目录>` |
| 24 | `KeyError: 'rmvpe_root'` | 同上 | `os.environ["rmvpe_root"] = <rmvpe目录>` |
| 25 | `TypeError: path should be ... not NoneType` | 自动索引解析用到 `index_root` 为 None | 显式传 index，并 monkeypatch `get_index_path_from_model` 返回 `""` |
| 26 | `vc_single() takes 10 positional arguments but 11 were given` | 参数顺序/个数记错 | 正确顺序：`sid, input, f0_up_key, f0_method, file_index, index_rate, resample_sr, rms_mix_rate, protect` |
| 27 | 转换成功但返回错误 | 新版 status 文案不是 `"Success"` | 判断返回值是否为 `(sr, audio)` 元组，而不是判断 status 字符串 |
| 28 | 每次转换要 60 秒 | CLI 每次重新加载模型 | 写**常驻服务** `rvc_server.py`（本项目已提供），模型只加载一次 |

## 五、语音效果（说话）

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 29 | 开头一两个字不清楚 | RVC 特征提取在首帧缺上下文 | 转换前**垫 300ms 静音**，转换后裁掉（本项目已内置） |
| 30 | 第一句语速明显比后面快 | `cut5` 按句切，首句短 | 改 `cut0` 整段合成（本项目默认） |
| 31 | 声音发闷、咬字不清 | 模型输出偏暗、峰值低 | 3kHz 提亮 + 峰值归一 0.9 |
| 32 | 声音"有气无力" | 同上 | 提亮 + 归一 + 适配合适参考音 |
| 33 | 说话像唱歌 | 参考音用了**唱歌**素材 | 参考音换成**说话**素材 |
| 34 | 情绪永远一个调 | TTS 只控制语速 | 加 `--emotion` 预设（语速/提亮/音高一起变），6 档 |
| 35 | 中英混合读错/跳过 | 单语言模型 | `--lang auto`：按语言分段合成再拼接 |
| 36 | 推脱不发语音 | 人格里没有硬规则 | 写死「最多推脱一次，再坚持必须发」 |
| 37 | 别人让它"说一句"却回文字 | 没判断意图 | 规则：出现"说/念/发语音"→语音；"打字/发文字"→文字；拿不准优先语音 |
| 38 | 语音和唱歌音色不一致 | 用了不同的 RVC 模型 | 统一同一个 9850 服务、同一模型 |

## 六、唱歌效果

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 40 | 前奏 20 秒太长 | 原曲前奏长 | 测人声进入点，超 `intro-max` 就整体前移（默认 8 秒） |
| 41 | 结尾切半句 | 固定时长硬切 | 在目标时长附近找 ≥150ms 换气点，延到整句结束（最多 +5 秒） |
| 42 | 人声和伴奏打架/跑调 | **只降了人声的调，伴奏没降** | 伴奏用 `asetrate+atempo` 同步降同样半音 |
| 43 | 声音尖、像小孩 | 直接 +12（整整一个八度） | 按原唱音高反推（+5~+7）；+12 只在原曲音域确实低时用 |
| 44 | 声音闷、偏低 | 固定音高对高音歌偏低 | 每首自动定调（测原唱中位 F0 → 目标 290Hz） |
| 45 | 高音破音/沙哑 | 超出模型训练音域 | 降 pitch（-1~-2）；换主歌段落；RVC `protect 0.3~0.4` |
| 46 | 长句"上气不接下气" | 源人声换气 + 无压缩 | 人声加压缩（-18dB/2.0） |
| 47 | 某些字沙哑 | 原唱气声/RVC 保留过多 | protect 0.35 + 6.5k/9k EQ 衰减 |
| 48 | 爆音 | 峰值顶到 0dB | 双限幅，峰值 -2.5~-2.7dB |
| 49 | 声音小 | 目标响度低 | 人声 ×1.2、伴奏 ×0.75、loudnorm -14 LUFS |
| 50 | 说"唱某首歌"却从头唱 | 默认 start=0 | 自动找副歌（全曲响度最高窗口） |
| 51 | 音色"夹"/不像 | 模型本身偏幼 | 换模型（温柔少女16→yujie 等）；音色=模型决定 |
| 52 | 匹配到 Live 版 | 歌名近似 | 对 `live/演唱会` 版本降权 |
| 53 | 说"唱晴天"找不到 | 动词被当歌名 | 剥离"唱/来/一首/点歌"等前缀 |

## 九、设计决策总结（为什么这么做）

1. **RVC 常驻服务**而不是每次 CLI：60 秒启动 → 20 秒转换，体验差一个数量级
2. **自动定调/自动选段/整句对齐**：固定参数对每首歌都不合适，用户感受是"每首歌都不一样"
3. **人声与伴奏同步变调**：这是最容易忽略但影响最大的一条
4. **先降调再谈音质**：破音/沙哑 80% 是音高超出音域，不是模型问题
5. **音色=模型**：觉得不像/夹，换模型比调参数有效
6. **文件纪律**：只保留最终产物，避免工作区被测试文件淹没
7. **隐私默认脱敏**：所有配置模板用占位符，避免误提交
