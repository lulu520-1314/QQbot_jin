# 11 · 让 AI 帮你搭（DSH / Claude Code / Cursor / Copilot 通用）

你不需要懂代码。把下面这段**直接粘给任意一个能执行命令的 AI 编程助手**，
它就能照着仓库把环境搭起来。

## 一、先决条件

- 有一台 Windows 电脑（macOS/Linux 也能跑，但脚本里是 Windows 路径，需自行改）
- 网络能访问 GitHub（或已按本文档配置代理）
- 已安装：QQ NT、NapCat、DeepSeek Harness、Python 3.10+、Node.js 20+、FFmpeg

> 没装的先看 [环境准备](01-环境准备.md)。

## 二、复制这段给 AI

```text
你是一个部署助手。请按 https://github.com/lulu520-1314/QQbot_jin 这个仓库，
在我这台 Windows 电脑上把"小鲸 QQ Bot"搭起来。要求：

1. 先 git clone 仓库到一个目录（或者直接读 GitHub 上的文件），通读 README 和 docs/。
2. 检查我电脑上已有哪些依赖（python / node / ffmpeg / 已装的 DSH / 已装的 NapCat），
   缺的列清单告诉我，不要擅自装大型软件。
3. 按 docs/01 装 Python 依赖（注意 numpy==1.26.4、librosa==0.10.2、transformers==4.49）。
4. 按 docs/02 配置 DSH 插件（cordis.patch.yml）——token/QQ 号我来填，你留占位符。
5. 按 docs/03 把 configs/AGENTS.example.md 复制成 workspace/AGENTS.md。
6. 按 docs/06 帮我准备 RVC 音色模型（先告诉我下载哪个、放哪里）。
7. 启动顺序：NapCat → RVC 服务 → TTS 服务 → DSH。
8. 每一步做完做一次验证（端口通不通、脚本能不能跑），把结果告诉我。
9. 所有要改的绝对路径，先列出来问我确认，再改。
10. 不要动我电脑上其他项目的文件。
```

## 三、不装 DSH 也能用吗？

可以。这个仓库的**声音部分**（`scripts/`）是独立的：

- `say.py`：文字 → 语音
- `cover.py`：翻唱
- `songreq.py`：点歌/切片

你可以只把它当"命令行工具"用，不接 QQ。
接 QQ 才需要 DSH + NapCat。

## 四、其他 AI 工具怎么用

| 工具 | 用法 |
|---|---|
| **DSH** | 在对话里贴上面那段 prompt，它会自己读仓库、跑命令 |
| **Claude Code / Cursor / Windsurf** | 同样贴 prompt；先 `git clone` 到本地再让它读 |
| **Copilot Chat** | 适合问"这段代码干什么"，不适合全自动搭 |
| **不借助 AI** | 直接照 docs 01→10 顺序做，纯手工约 1~2 小时 |

## 五、验收清单（搭完自查）

```text
[ ] NapCat 能登录小号，curl http://127.0.0.1:13200/get_login_info 有 QQ 号
[ ] DSH 启动后，QQ 里发 /help 有回复
[ ] /help 是两条消息（标题 + 分组卡片）
[ ] RVC 服务：http://127.0.0.1:9850 返回 {"ok": true}
[ ] TTS 服务：http://127.0.0.1:9880/docs 能打开
[ ] say.py --text "测试" --rvc 能生成 wav
[ ] cover.py --song <一首歌> --outdir out 能在 3~5 分钟出歌
[ ] /点歌 晴天 能出语音
[ ] /点歌 原唱 晴天 能出原曲切片
```

## 六、常见卡点（AI 也常犯错的地方）

| 卡点 | 正确做法 |
|---|---|
| 用错 Python | 音频环境必须用你装好的那个（如 `py310\python.exe`），不要用系统 python |
| 装了 numpy 2.x | 降到 1.26.4，否则 RVC 各种报错 |
| transformers 版本 | RVC 环境锁 4.49；GPT-SoVITS 单独环境装 ≥4.51 |
| NapCat 端口 | 用 13200/13201，别用 3000/3001（可能被系统保留） |
| 路径 | 脚本里全是绝对路径，换电脑必须全局替换 |
| RVC 服务 | 必须先启动再跑 say/cover，否则报连接失败（脚本会自动拉起，但要等 60 秒） |
