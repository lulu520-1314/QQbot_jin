# 13 · 音色模型从哪来（含本项目默认模型来源）

## 一、本项目默认模型

**`温柔少女16.pth`**（约 49MB，女声，成熟自然、不"夹"）

来源（HuggingFace 公开模型仓库）：

```
https://huggingface.co/lowo/RVC-weights
文件名：温柔少女16.pth
```

下载（国内可用 hf-mirror）：

```bash
pip install huggingface_hub
HF_ENDPOINT=https://hf-mirror.com python -c "
from huggingface_hub import hf_hub_download
p = hf_hub_download(repo_id='lowo/RVC-weights', filename='温柔少女16.pth',
                    endpoint='https://hf-mirror.com')
print(p)"
```

放这里：

```
rvc_pack\Retrieval-based-Voice-Conversion-WebUI-main\assets\weights\温柔少女16.pth
```

然后改 `rvc_model.txt` 里写上 `温柔少女16.pth`，重启 RVC 服务。

> 同一个仓库里还有作者试过的：
> - `温柔少女14.pth`（同系列，更成熟一点）
> - `yujie.pth`（御姐音）
> - `极高质量_纯净女声_...Yamine_Renri_V2_...zip`（清亮、高音域，适合唱歌）

## 二、常见公开模型仓库

| 来源 | 地址 | 说明 |
|---|---|---|
| HuggingFace · lowo/RVC-weights | `huggingface.co/lowo/RVC-weights` | 约 500 个 RVC 模型，中文命名多，本项目默认模型来源 |
| HuggingFace · 搜索 RVC | `huggingface.co/models?search=rvc` | 关键词 `rvc`、`so-vits-svc`、`voice conversion` |
| ModelScope（魔搭） | `modelscope.cn` 搜「RVC 模型」 | 国内速度快 |
| GitHub · RVCModel/RVC_Model | `github.com/RVCModel/RVC_Model` | 模型索引/合集 |
| 各类社区整合包 | B站/贴吧/QQ群 | 良莠不齐，注意安全 |

> 模型文件通常只有 `.pth`（50~200MB）；带 `.index` 的相似度更高。

## 三、模型怎么选（听感对照）

| 关键词 | 听感 | 适合 |
|---|---|---|
| 温柔少女 / 少女音 | 年轻、柔和 | 日常聊天、抒情歌 |
| 御姐 / 成熟女声 | 低沉、有厚度 | 中低音歌、慢歌 |
| 甜美 / 甜妹 | 甜腻、偏高 | 轻快歌 |
| 清亮 / 高音域 | 通透、音域宽 | 高音多的歌（如周杰伦） |
| 男声 / 正太 | — | 男声原曲翻唱 |

**同一个人声在不同模型下差别很大**。觉得"夹"、"不像"、"闷"，先换模型，再调参数。

## 四、下载后的检查

1. 文件大小：`.pth` 一般 50~200MB，太小说明损坏
2. 版本：RVC v2 模型（48k/40k 都行）；v1 模型老，音质差
3. 索引：`.index` 与模型同名放同目录，服务会自动加载
4. 试听：先用 `cover.py` 跑一小段 25 秒，确认没有爆音/杂音

## 五、版权与合规（重要）

- 用**真人/明星/声优**的声音模型：仅限个人学习娱乐，**不要公开发布、不要商用**
- 公开模型仓库里很多模型来源不明，使用前自行判断
- 想公开发布作品：用**自己训练**的模型，或用明确标注可商用的模型
- 训练素材：用**你自己的声音**或已获授权的素材

## 六、想自己训练？

见 [音色模型与训练](06-音色模型与训练.md)：

- 5~10 分钟干净素材
- 数据切分 → RVC WebUI 训练（48k / v2 / 200 epoch）
- 或者用 GPT-SoVITS 微调（更适合作"说话"）

如果只是想要"好听的女声"而不追求"像我"，**直接用公开模型最省事**。
